# Cross-Device Distribution — v2

## Goal

Make Personal Skill Library available in normal ChatGPT beyond a single desktop installation, including web/mobile where supported.

## Current supported path

OpenAI uses one universal plugin directory shared by ChatGPT and Codex. A published skills-only plugin can be listed there after submission and review.

This repository is **not automatically submitted or published**. Publishing would make the plugin a public directory listing, so it requires an explicit decision by the owner.

## Why v2 does not auto-publish

The library is personal and currently includes user-specific workflows. Publishing to the universal directory is a separate privacy/product decision.

Do not publish or submit without explicit owner approval.

## If public cross-device distribution is approved later

1. Review every skill for user-specific or sensitive information.
2. Remove or generalize account-specific links and private assumptions.
3. Complete OpenAI publisher identity verification.
4. Create a **Skills only** submission in the plugin submission portal.
5. Upload the same plugin skill bundle.
6. Add listing metadata, starter prompts, and required attestations.
7. Submit for review.
8. After approval, explicitly publish.
9. Install the published plugin from the universal Plugin Directory on supported ChatGPT surfaces.

## Private cross-device note

GitHub marketplace import/sync for cloud-managed distribution is documented for eligible managed workspaces/admins. A personal Plus account should not be assumed to have that private cloud distribution path.
