# Privacy boundary for Batch 3

The source memory export is intentionally **not** mirrored into this public repository.

Excluded categories include:

- identity/profile records;
- employer, compensation, education/career specifics not needed for an agent contract;
- family/partner/people memory;
- exact home/location details;
- exact local machine paths and account identifiers;
- hobby/home context unrelated to the migrated agent architecture;
- the combined raw memory document.

Agent/project requirements are rewritten into portable system contracts using generic placeholders where machine-specific detail is not essential.

If a future migration needs raw personal memory as a canonical archive, use a private repository or private file store rather than this public skills repository.
