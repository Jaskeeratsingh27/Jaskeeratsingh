1. Original authoritative project/skill/runtime file.
2. Original chat/project export showing the actual instruction/artifact content.
3. Batch 4 verbatim persistent-memory record.
4. Batch 3 summarized persistent-memory record.
5. Reconstruction/specification created during migration.
