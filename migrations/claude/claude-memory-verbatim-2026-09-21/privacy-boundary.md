# Privacy boundary — Batch 4

The source archive is a verbatim personal-memory export. The public canonical repository receives only architecture-level reusable material.

## Excluded from public GitHub

- personal identity/profile details beyond what is necessary for an agent specification;
- people/relationship notes;
- compensation and detailed employment history;
- exact home/local filesystem paths;
- private home/device details not needed for a reusable system design;
- potentially employer-specific/internal API notes, endpoints, credentials, or automation details;
- unrelated personal lifestyle/hobby memory.

## Preserved publicly in sanitized form

- reusable agent/system purposes and contracts;
- stage/gate/failure-control architecture;
- evidence/completeness status;
- safe source hashes for agent/project memory files;
- migration decisions explaining why missing bundles were not fabricated.

The untouched uploaded ZIP remains the verbatim evidence source outside the public repository.
